# stryke_ymap

![Bannière map](/img/banner-map.png)

Pack **ymap** fusionné (végétation, borders, checkpoints, etc.). `this_is_a_map 'yes'`.

## Emplacement

`resources/[assets]/stryke_ymap/`

## Démarrage

```ini
ensure [assets]
```

## Contenu

Stream : `.ymap`, `.ytyp`, `.ydr`, `.ynd` sous `stream/`.

## Vérification

Zones custom / décors du pack visibles en jeu ; pas de collision manquante sur les ajouts connus.
